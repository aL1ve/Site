Privacy Policy — PW Gifts

Extension by simple · Last updated: October 21, 2026

EnglishРусский
Summary: PW Gifts processes a small amount of information locally in your browser to provide gift-selection tools, remember your language, and continue a promo-code activation that you initiate. It does not send data to the extension developer.

1. About the extension

PW Gifts is a Chrome extension that provides a compact interface for selecting gifts and redeeming promo codes on https://pwonline.ru/.

2. Information processed

  • Page content related to gift selection: on pwonline.ru pages, the extension checks gift-list checkboxes and their state to display a count and change selection when you use the extension controls. It does not collect or transmit the page content to the developer.
  • Promo code entered by you: if you start activation from a page other than pin.php, the code may be temporarily stored in Chrome extension local storage so it can be carried across navigation to the site's activation page. The temporary entry is removed after the activation form is located or when the request expires or times out.
  • Language preference: your RU/EN interface choice is stored locally in chrome.storage.local.

3. How information is used and shared

This information is used only to display the extension interface, count and select gifts, remember the selected language, and place the promo code you entered into the website's native activation form. The promo code is submitted to pwonline.ru only as part of the activation you initiate. The website then processes it under its own policies.

The extension developer does not receive promo codes, gift selections, page contents, or account credentials. PW Gifts does not include analytics, third-party advertising, tracking services, or a developer-operated collection server. Information handled by the extension is not sold or shared with the developer or unrelated third parties.

4. Permissions and website access

The extension runs on HTTPS pages of pwonline.ru so its panel can be available throughout that website. It interacts with the site's gift-list controls and promo-code form when you use the related features. The storage permission stores the language preference and the temporary promo-code activation state. The extension does not request access to browser cookies or browsing history.

5. User control and security

Promo-code activation is initiated by you. The extension does not automatically transfer gifts and does not bypass server-side restrictions. You can enter the code directly on the website instead of using the extension panel. Removing the extension stops its further processing; extension-local data can be cleared through Chrome's extension settings.

6. Changes to this policy

This policy may be updated if the extension's functionality or data practices change. The published policy and the Chrome Web Store disclosures should reflect the extension's actual behavior.

7. Contact

For privacy questions, use the support contact shown on the PW Gifts Chrome Web Store listing.

Политика конфиденциальности — PW Gifts

Расширение by simple · Последнее обновление: 21 октября 2026 г.

Кратко: PW Gifts локально обрабатывает в браузере небольшой объём информации, необходимый для выбора подарков, сохранения языка интерфейса и продолжения инициированной пользователем активации промокода. Данные не отправляются разработчику расширения.

1. О расширении

PW Gifts — расширение Chrome с компактной панелью для выбора подарков и активации промокодов на сайте https://pwonline.ru/.

2. Обрабатываемая информация

  • Содержимое страницы, связанное с выбором подарков: на страницах pwonline.ru расширение проверяет флажки списка подарков и их состояние, чтобы показать счётчик и менять выбор по команде пользователя. Содержимое страницы не собирается и не отправляется разработчику.
  • Введённый пользователем промокод: если активация начинается не на pin.php, код может временно сохраняться в локальном хранилище расширения Chrome, чтобы перенести его при переходе на страницу активации сайта. Временная запись удаляется после обнаружения формы активации либо по истечении срока ожидания.
  • Языковые настройки: выбор RU/EN хранится локально в chrome.storage.local.

3. Использование и передача информации

Информация используется только для показа интерфейса расширения, подсчёта и выбора подарков, сохранения языка и подстановки введённого пользователем промокода в штатную форму сайта. Промокод отправляется на pwonline.ru только в рамках активации, инициированной пользователем. Далее сайт обрабатывает код согласно собственным правилам.

Разработчик не получает промокоды, выбор подарков, содержимое страниц или учётные данные. В PW Gifts нет аналитики, сторонней рекламы, трекеров или сервера разработчика для сбора информации. Данные не продаются и не передаются разработчику или посторонним третьим лицам.

4. Разрешения и доступ к сайту

Расширение работает на HTTPS-страницах pwonline.ru, чтобы его панель была доступна на всём сайте. При использовании соответствующих функций оно взаимодействует с элементами списка подарков и формой промокода. Разрешение storage используется для сохранения языка и временного состояния активации. Расширение не запрашивает доступ к cookies браузера или истории просмотров.

5. Контроль пользователя и безопасность

Активацию промокода инициирует пользователь. Расширение не передаёт подарки автоматически и не обходит серверные ограничения. Вместо панели расширения можно вводить промокод непосредственно на сайте. После удаления расширения дальнейшая обработка прекращается; локальные данные расширения можно очистить в настройках Chrome.

6. Изменения политики

Политика может обновляться при изменении функциональности расширения или практик обработки данных. Опубликованный документ и сведения в Chrome Web Store должны соответствовать фактическому поведению расширения.

7. Контакты

По вопросам конфиденциальности используйте контакт поддержки, указанный в карточке PW Gifts в Chrome Web Store.
