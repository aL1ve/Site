Privacy Policy — PW Collection

Created by simple · Last updated: October 21, 2026

Русский English
Summary. PW Collection automates actions in the Collection mini-game on pwonline.ru. It processes game state locally within the user's current authenticated session to perform the user-selected workflow, including moving completed categories, and does not send data to the developer.

1. About the extension and its purpose

PW Collection is a free Chrome extension that automates actions on the Collection mini-game page: https://pwonline.ru/minigames.php?game=collection&doo=display. It lets the user choose a target category, start or stop automation, view an action counter, and receive game-status messages.

2. Information processed

  • Game state: the extension receives responses from pwonline.ru game endpoints that are needed to determine category progress and available resources. These values are used to control automation, update the counter, and apply stop conditions.
  • In-game actions: after the user presses Start, the extension sends requests to the site's game endpoints. These include performing game turns, checking the game state, and, when the selected conditions are met, using the game's category-transfer action to move a completed category below the target category. The loop continues while automation is running or until a stop condition is met; the user can press Stop.
  • Interface language: the selected RU/EN language is stored locally in Chrome extension storage so the preference is retained between page visits.

The extension does not maintain a separate database of game data. It is not designed to read passwords or extract cookies, and it does not store cookies separately.

3. Requests and authentication

Game requests are sent only to pwonline.ru over HTTPS and use the browser's current authenticated session. This allows the website to process game actions for the signed-in user. The extension does not send login details, passwords, cookies, or game information to the developer or third-party services.

4. Data sharing, analytics, and advertising

The extension does not include third-party analytics, trackers, or third-party advertising. It does not send data to a developer-operated server, sell data, or share it with unrelated third parties. The pwonline.ru website receives the requests required to carry out game actions and processes them under its own terms and privacy policy.

5. Developer support

The interface may display a QR code for voluntary developer support. The QR code is included in the extension package as a local file. The extension does not receive payment credentials or process the user's payments.

6. Permissions and remote code

Access to https://pwonline.ru/minigames.php* is needed to display the panel on the Collection page and send game requests to endpoints on that same website. The storage permission is used to save the selected interface language. Executable code is bundled with the extension; remote JavaScript files are not loaded.

7. Policy changes

If the extension's functionality or data practices change, this policy will be updated and the Chrome Web Store disclosures will be kept consistent with the product's actual behavior.

8. Contact

For privacy questions, use the support contact shown on the PW Collection Chrome Web Store listing.

PW Collection is an independent browser extension and is not affiliated with the pwonline.ru website operator.
