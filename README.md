# simple — browser extension privacy pages

This public repository hosts the privacy policies used by extensions published under the `simple` nickname.

## Privacy policies

- **PW Gifts** (RU + EN): [pw-gifts-privacy-policy.html](https://al1ve.github.io/Site/pw-gifts-privacy-policy.html)
- **PW Collection** (Russian): [privacy-policy.html](https://al1ve.github.io/Site/privacy-policy.html)

## PW Gifts

PW Gifts provides an on-page interface for gift selection and promo-code activation on `https://pwonline.ru/`. It stores the selected interface language and a short-lived pending activation request locally in Chrome extension storage. A promo code is submitted to pwonline.ru only after the user initiates activation through the extension. The extension does not automatically transfer gifts or bypass server-side restrictions.

The privacy page describes the information processed by the extension, local storage use, site access, and data sharing practices in both English and Russian.

## Maintenance

The privacy policy must be kept in sync with the published extension's actual behavior and with the declarations in the Chrome Web Store Developer Dashboard.
