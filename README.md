# simple — privacy policies for browser extensions

This public repository hosts privacy policies for extensions published under the `simple` nickname.

## Privacy policies

- **PW Collection — Russian:** https://al1ve.github.io/Site/privacy-policy.html
- **PW Collection — English:** https://al1ve.github.io/Site/privacy-policy-en.html
- **PW Gifts — Russian and English:** https://al1ve.github.io/Site/pw-gifts-privacy-policy.html

## PW Collection

PW Collection automates actions in the Collection mini-game on `https://pwonline.ru/`. It processes game-state responses locally, uses the browser's current authenticated session to make game requests after the user starts automation, and can move completed categories through the game's category-transfer action. It stores the selected interface language locally. It does not send data to the developer and does not include third-party analytics or advertising.

## PW Gifts

PW Gifts provides an on-page interface for gift selection and promo-code activation on `https://pwonline.ru/`. It stores the selected interface language and a short-lived pending activation request locally in Chrome extension storage. A promo code is submitted to pwonline.ru only after the user initiates activation through the extension. The extension does not automatically transfer gifts or bypass server-side restrictions.

## Maintenance

These documents must remain consistent with the corresponding extension versions and the data-use disclosures in the Chrome Web Store Developer Dashboard. Update the policies if extension functionality or data practices change.
