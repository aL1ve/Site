Политика конфиденциальности — PW Collection

Версия документа: 8 октября 2026 года

Кратко: PW Collection не собирает и не отправляет разработчику пользовательские данные. Расширение использует текущую авторизованную сессию браузера только для работы с мини-игрой Collection на pwonline.ru.

1. Какие данные обрабатывает расширение

Расширение работает только на странице https://pwonline.ru/minigames.php?game=collection&doo=display. Для выполнения функций оно обращается к игровым endpoint'ам pwonline.ru в рамках текущей сессии пользователя.

Расширение не создаёт собственную базу пользовательских данных, не отправляет данные разработчику и не использует стороннюю аналитику.

2. Cookies и авторизация

Запросы к pwonline.ru выполняются с учётом текущей авторизованной сессии браузера. Расширение не читает и не сохраняет cookies отдельно, не извлекает логины или пароли и не передаёт данные авторизации разработчику или сторонним сервисам.

3. Передача третьим лицам

Пользовательские данные не продаются и не передаются третьим лицам. Расширение не использует данные для таргетированной или поведенческой рекламы.

4. Поддержка разработчика

В интерфейсе есть добровольная ссылка «❤️ Поддержать разработчика» и локальный QR-код. Расширение не получает и не обрабатывает платёжные реквизиты пользователя.

5. Безопасность

Расширение использует HTTPS для обращения к pwonline.ru. Код расширения не загружает удалённые JavaScript-файлы и не отправляет данные в собственные серверы разработчика.

6. Изменения политики

При существенных изменениях функциональности или практик обработки данных этот документ будет обновлён, а сведения в Chrome Web Store будут приведены в соответствие с фактическим поведением расширения.

7. Контакт

Создатель: simple. Для вопросов по расширению используйте контактный канал, указанный на странице PW Collection в Chrome Web Store.
